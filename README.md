# Ecommerce-Sales-Power-BI-Dashboard
Interactive Ecommerce Sales Dashboard Created Using Power BI

# Project overview 
This project is an interactive E-Commerce Sales Dashboard developed in Microsoft Power BI.
The dashboard turns raw data from e-commerce into meaningful business insights on sales, quantity, profit, customers, categories, payment methods and monthly performance.

# Objectives
- Sales performance overall review
- Monitor trends in profit
- Analysis of category and sub category sales
- Breakdown sales customer wise
- Know payment mode distribution
- Track monthly profit trends
- Check performance of states
- Design an interactive business dashboard

# Tool & Technologies
- Microsoft Power BI
- Power Query
- Data Cleaning
- Data Transformation
- Data Visualization
- Business Intelligence

# Dashboard Features 
-Total Sales
-Total Quantity
-Total Profit
- Average Sales
- Category Analysis
- Sub Category Analysis
- Customer Analysis
- Payment Mode Analysis
- Monthly Profit Analysis
- State Filter

# Key Insights
The dashboard provides an interactive view of e-commerce performance, and helps to detect patterns in sales, quantity and profitability across various business dimensions.
